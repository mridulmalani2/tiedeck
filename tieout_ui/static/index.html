Local only · nothing leaves this machine unless you turn on content review

1  Deck

The deck to audit. Nothing is uploaded anywhere: the file is copied into a temporary directory on this machine and deleted when the server stops.

Drop a .pptx here, or click to choose

2  House style

Audit against a client already onboarded, or learn a new one from this deck. Learning from the deck you are about to audit tells you nothing — use a deck the client has already approved.

3  Confirm what was derived

Every line below was measured from the reference deck, with the evidence for it. Untick anything that is not actually a house rule: the rule that reads it stops running and the profile records that you decided so. Values are not editable here on purpose — typing a number a deck does not support is how you get a client whose own approved deck is reported as wrong. Edit the YAML for that.

4  Content review (optional)

Off by default, and TieOut needs no key or network without it. Turned on, the deck's text is sent to a language model to catch what arithmetic cannot — a headline that contradicts its own table. Every name is replaced first, and you see exactly what would be sent before anything is.
